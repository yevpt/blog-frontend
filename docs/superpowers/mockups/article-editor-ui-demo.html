为什么文章页需要单独定制编辑器

评论和碎语更强调快速输入，文章编辑则需要更稳定的空间感。正文区域应该更高、更安静，并且让工具栏服务于长文本写作。

这个 demo 里的编辑器只是视觉原型；正式实现会复用公用 inline 类型编辑器，并通过 className 和插入行为做文章页定制。

右侧的封面、分类、标签和背景音乐保持 sticky，让作者不需要离开正文上下文就能完成发布配置。
